# Technical results

The README tells the story in percentages. This page gives the same results as effect sizes
(Cohen's d) with intervals, run by run, so you can compare against published studies. New to the terms?
Read [explained.md](explained.md) first. Every number is in `analysis/results/` and is regenerated by
`python analysis/reproduce.py`.

Human reference values (Many Labs 1; see `src/wre/human_reference.py`): framing d = 0.71, sunk cost
d = 0.27, anchoring d about 1.9 (different quantities, so rough), allowed/forbidden d = 0.76.
All data were collected on 2026-11-01.

## Run 1: 13 OpenAI models, four tests ([results](../analysis/results/run1_openai.txt))
The pre-registered stop/continue checks passed: the tests separate models, and two frontier models show
a non-zero effect on at least one test. Highlights: `gpt-6.1-sol` and `gpt-6-astra` have framing d = 0.00;
9 of the 13 models show framing effects at or above about 0.71; the first allowed/forbidden topics
were at floor (11 of 13 models never gave the restrictive answer), so those items were revised for run 2.

## Run 2: 3 Anthropic models, plus an OpenAI re-run on revised items ([results](../analysis/results/run2_anthropic_and_rerun.txt))
- **Framing:** Sonnet 5.5 d = +2.50, Opus 5.5 +1.93 in this first run (later re-measured in run 3).
  Haiku 4.5 answered "B" on 100% of framing prompts, so its framing d is zero by construction (excluded).
- **Sunk cost after fixing the free-ticket wording:** paid-versus-free d stays above 0.15 for the frontier
  models (Sol +0.44, Astra +0.46, Opus +0.93, Sonnet +1.42; human 0.27). Reported as paid-versus-free
  sensitivity, not as the sunk-cost fallacy.
- **Allowed/forbidden** now spreads models out, but mostly by yes/no bias (acquiescence from +0.57 for
  `gpt-4o` to -0.82 for `claude-opus-5.5`; humans -0.17), and Opus gives no parseable answer on 54% of
  these prompts (it mostly declines to give a personal verdict).
- **Anchoring** is weak in every model (rank d between -0.33 and +0.43; humans about 1.9 on different items).

## Run 3: framing robustness ([results](../analysis/results/run3_framing_robustness.txt), [figure](../analysis/results/fig1_framing_by_model.png))
Verdict by the pre-registered rules: **headline firm**.
- Sol d = 0.00 and Astra d = 0.01 (sure option chosen 100% under both wordings, in both label styles and
  both positions).
- Sonnet 5.5 d = +2.13 [1.66, 2.80] and Opus 5.5 d = +2.19 [1.63, 2.59], both above 1.0 in each label
  style. Intervals are 90%, resampling scenarios.
- Model ordering is stable between earlier runs and run 3 (rank correlation 0.91).
- Four OpenAI models are format-sensitive (`gpt-5.1`, `gpt-5.2`, `gpt-5.6-luna`, `gpt-6-luna`); Haiku is
  position-biased.
- The swing depends on where the sure option is listed. Split by layout, most models show a much smaller swing when the sure option is listed first than when it is listed second (Sonnet 5.5: 8 vs 89 points; Opus 5.5: 14 vs 39); Sol and Astra are 0 in both. Under the loss wording Sonnet picks whichever option is listed first. The pooled swings above average the two layouts, which is the intended design. See [run3_swing_by_position.txt](../analysis/results/run3_swing_by_position.txt) and [chart_swing_by_position.png](../analysis/results/chart_swing_by_position.png).

**Reading d carefully.** Opus's d (2.19) is larger than Sonnet's (2.13) even though its swing between
wordings is smaller (26 vs 49 percentage points), because d works on odds and Opus sits near 100% in
both wordings ([explained.md](explained.md), section 3). Saying "about three times the human effect"
is correct for d but misleading in everyday terms; the README reports points instead.

## Run 4: one-line instructions ([results](../analysis/results/run4_prompting.txt), [figure](../analysis/results/fig2_prompting.png))
Verdict by the pre-registered rules: **prompting does not calibrate**. No anchor model landed in the
human-sized band (0.36 to 1.42) under both human-style instructions.

| model | no instruction | `typical` | `gut` | `rational` |
|---|---|---|---|---|
| gpt-6.1-sol | 0.00 | +1.66 | +0.62 | 0.00 |
| gpt-6-astra | 0.01 | 0.00 | 0.00 | 0.00 |
| claude-sonnet-5.5 | +2.13 | +2.06 | +2.32 | +0.09 (invalid) |
| claude-opus-5.5 | +2.19 | +4.29 | +4.29 | 0.00 |

Opus's 4.29 is the ceiling of the estimator: it chose the sure option 100% of the time under the gain
wording and 0% under the loss wording, so the interval has no width. Sonnet's `rational` cell is invalid
because it picked the first-listed option 98% of the time. These cells have one answer per question
(two for Sol), so cells near a band edge are not precise.

The sunk cost cells in plain units (average rating with a paid ticket minus with a free ticket, in points of the
1 to 9 scale, with the number of scenarios that go up or down) are in
[run4_sunkcost_gaps.txt](../analysis/results/run4_sunkcost_gaps.txt). The no-instruction column there comes from run 2.

## Sunk cost: does the gap grow with the price?
The paid version of each sunk cost scenario names a price ($45 to $150). If the gap were a response to money
spent, it should be larger where the price is higher. For each of the 16 models, [run2_sunkcost_price_check.txt](../analysis/results/run2_sunkcost_price_check.txt)
correlates the per-scenario gap with the scenario price. The correlations run from -0.28 to +0.48, ten are positive and
six negative, and none passes the roughly 0.58 needed to tell a correlation over 12 scenarios from zero. So there is no
consistent sign and no clear relationship, which fits reading the gap as paid-versus-free sensitivity and not as an effect of the amount spent. With 12 scenarios per model this
can only rule out a strong relationship, not a weak one.

## Scenario-level intervals in percentage points and rating points
The effect sizes above are in Cohen's d. [item_level_intervals.txt](../analysis/results/item_level_intervals.txt)
reports the same effects in the units used for the human reference values (framing swing in percentage points,
sunk cost gap in rating points), with the scenario as the unit of replication: each model's effect is the mean
of its 12 scenario differences, with a 95% t interval on the spread of those differences and a scenario
bootstrap next to it. In this balanced design that mean is the fixed effect of a linear mixed model with a random
intercept and a random wording slope for scenario; [item_level_mixed_check.txt](../analysis/results/item_level_mixed_check.txt)
(optional, needs `pip install -e ".[stats]"`) fits that model and gets the same estimates, with standard errors
that agree closely.

- **Framing.** Claude Sonnet 5.5 swings 49 points (95% interval 39 to 58, positive in all 12 scenarios);
  Claude Opus 5.5 swings 26 (4 to 49); GPT-4.1 21 (4 to 38). GPT-6.1 Sol and GPT-6 Astra have no spread across
  scenarios (0 in every one), so their intervals are single points and say nothing about uncertainty.
- **Layout and label.** The sure plan is listed first under one label style and second under the other within a
  scenario, so layout and label style are crossed by scenario and can be estimated separately. The layout effect
  (swing with the sure plan second minus first) is 81 points for Claude Sonnet 5.5 (51 to 110), 25 for Claude Opus 5.5
  (1 to 49) and 0 for Sol and Astra. The label effect for GPT-5.1 is -50 (-87 to -13) and for GPT-6 Luna -36
  (-68 to -4). Intervals on these two effects assume that the layout and label effects add up and, being
  linear-scale intervals on shares, can run past 100.
- **Sunk cost.** GPT-6.1 Sol 0.56 (0.25 to 0.86) and GPT-6 Astra 0.58 (0.29 to 0.88) both contain the human
  0.61 and exclude zero; GPT-4.1 2.43 (1.91 to 2.96), Claude Sonnet 5.5 1.48 (0.98 to 1.97) and GPT-4o 1.32
  (0.73 to 1.91) are above it; Claude Opus 5.5 1.17 (0.61 to 1.73) reaches it at the lower end.
- **One-line instructions.** The same intervals for the four anchor models under each instruction are in the
  last section of the file. Run 4 has one answer per prompt (two for GPT-6.1 Sol), so those intervals mix scenario
  spread with answer noise.

These are descriptive intervals for 16 models and two tests, with no correction for multiple comparisons.

## Canonical wording against fresh scenarios
Each test has one canonical item (a paraphrase of the textbook version). [canonical_vs_fresh.txt](../analysis/results/canonical_vs_fresh.txt)
sets each model's canonical effect beside its fresh-scenario effect (framing from run 3, sunk cost from run 2).
The canonical item is a single scenario answered about six times per condition by each model, so a single model's
canonical number is noisy and has no interval; the informative quantity is the mean difference across models.

- **Framing.** Across the 15 models with canonical answers, the canonical swing is on average 11.6 points larger
  than the fresh swing, with a 95% bootstrap interval over models of -2.9 to +28.6 (larger in 9 models, smaller in 5,
  equal in 1). For the 10 models not marked unreliable it is +15.4 (-5.3 to +39.3). GPT-4o and GPT-4.1 swing 100
  points on the canonical wording (6 of 6 sure answers when worded as saved, 0 of 6 when worded as lost) and 28 and 21 on
  fresh scenarios; Claude Sonnet 5.5 swings 83 and 49. GPT-6.1 Sol is 0 on both. GPT-6 Astra has no canonical
  answers in run 3.
- **Sunk cost.** The mean canonical-minus-fresh gap is -0.12 rating points (-0.49 to +0.24; canonical larger in 6
  models, smaller in 10).

Across the 16 models, the fresh framing swing and the fresh sunk cost gap are only weakly related (Spearman
rank correlation 0.27 over all 16, 0.25 over the 11 whose framing result is not marked unreliable).

So on average the evidence for a stronger effect on the famous wording is weak, with a few large single-model
differences. One canonical scenario cannot separate recognition of the wording from a feature of that scenario.

## What to be careful about
See [limitations.md](limitations.md). In short: effect sizes describe these items and this prompt style at
low reasoning effort; per-model intervals are wide; the human numbers come from different stories; and
the same model name can behave differently later.
