# Technical results

The README tells the story in percentages. This page gives the same results as effect sizes
(Cohen's d) with intervals, run by run, so you can compare against published studies. New to the terms?
Read [explained.md](explained.md) first. Every number is in `analysis/results/` and is regenerated by
`python analysis/reproduce.py`.

Human reference values (Many Labs 1; see `src/wre/human_reference.py`): framing d = 0.71, sunk cost
d = 0.27, anchoring d about 1.9 (different quantities, so rough), allowed/forbidden d = 0.76.
All data were collected on 2026-11-01.

## Run 1: 13 OpenAI models, four tests ([results](../analysis/results/run1_openai.txt))
The pre-registered stop/continue checks passed: the tests separate models, and two frontier models show
a non-zero effect on at least one test. Highlights: `gpt-6.1-sol` and `gpt-6-astra` have framing d = 0.00;
9 of the 13 models show framing effects at or above about 0.71; the first allowed/forbidden topics
were at floor (11 of 13 models never gave the restrictive answer), so those items were revised for run 2.

## Run 2: 3 Anthropic models, plus an OpenAI re-run on revised items ([results](../analysis/results/run2_anthropic_and_rerun.txt))
- **Framing:** Sonnet 5.5 d = +2.50, Opus 5.5 +1.93 in this first run (later re-measured in run 3).
  Haiku 4.5 answered "B" on 100% of framing prompts, so its framing d is zero by construction (excluded).
- **Sunk cost after fixing the free-ticket wording:** paid-versus-free d stays above 0.15 for the frontier
  models (Sol +0.44, Astra +0.46, Opus +0.93, Sonnet +1.42; human 0.27). Reported as paid-versus-free
  sensitivity, not as the sunk-cost fallacy.
- **Allowed/forbidden** now spreads models out, but mostly by yes/no bias (acquiescence from +0.57 for
  `gpt-4o` to -0.82 for `claude-opus-5.5`; humans -0.17), and Opus gives no parseable answer on 54% of
  these prompts (it mostly declines to give a personal verdict).
- **Anchoring** is weak in every model (rank d between -0.33 and +0.43; humans about 1.9 on different items).

## Run 3: framing robustness ([results](../analysis/results/run3_framing_robustness.txt), [figure](../analysis/results/fig1_framing_by_model.png))
Verdict by the pre-registered rules: **headline firm**.
- Sol d = 0.00 and Astra d = 0.01 (sure option chosen 100% under both wordings, in both label styles and
  both positions).
- Sonnet 5.5 d = +2.13 [1.66, 2.80] and Opus 5.5 d = +2.19 [1.63, 2.59], both above 1.0 in each label
  style. Intervals are 90%, resampling scenarios.
- Model ordering is stable between earlier runs and run 3 (rank correlation 0.91).
- Four OpenAI models are format-sensitive (`gpt-5.1`, `gpt-5.2`, `gpt-5.6-luna`, `gpt-6-luna`); Haiku is
  position-biased.

**Reading d carefully.** Opus's d (2.19) is larger than Sonnet's (2.13) even though its swing between
wordings is smaller (26 vs 49 percentage points), because d works on odds and Opus sits near 100% in
both wordings ([explained.md](explained.md), section 3). Saying "about three times the human effect"
is correct for d but misleading in everyday terms; the README reports points instead.

## Run 4: one-line instructions ([results](../analysis/results/run4_prompting.txt), [figure](../analysis/results/fig2_prompting.png))
Verdict by the pre-registered rules: **prompting does not calibrate**. No anchor model landed in the
human-sized band (0.36 to 1.42) under both human-style instructions.

| model | no instruction | `typical` | `gut` | `rational` |
|---|---|---|---|---|
| gpt-6.1-sol | 0.00 | +1.66 | +0.62 | 0.00 |
| gpt-6-astra | 0.01 | 0.00 | 0.00 | 0.00 |
| claude-sonnet-5.5 | +2.13 | +2.06 | +2.32 | +0.09 (invalid) |
| claude-opus-5.5 | +2.19 | +4.29 | +4.29 | 0.00 |

Opus's 4.29 is the ceiling of the estimator: it chose the sure option 100% of the time under the gain
wording and 0% under the loss wording, so the interval has no width. Sonnet's `rational` cell is invalid
because it picked the first-listed option 98% of the time. These cells have one answer per question
(two for Sol), so cells near a band edge are not precise.

## What to be careful about
See [limitations.md](limitations.md). In short: effect sizes describe these items and this prompt style at
low reasoning effort; per-model intervals are wide; the human numbers come from different stories; and
the same model name can behave differently later.
